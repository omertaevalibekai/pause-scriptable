# Source

- `core.js`: platform-independent validation, event replay, history, goals, and craving pauses.
- `app.js`: English dashboard, forms, and browser / Scriptable storage adapters.
- `shell.html`: responsive interface and styles.
- `scriptable.js`: local journal, Home Screen widget, and WebView host.
- `autoupdate.js`: update launcher with a bundled offline fallback and separate code cache.

Run `npm run build` from the repository root after editing these files. Install the generated `Pause-Auto.js` on iPhone for automatic updates, or `Pause.js` for a fixed offline version.
