# Source

- `core.js`: platform-independent validation, event replay, history, goals, and craving pauses.
- `app.js`: English dashboard, forms, and browser / Scriptable storage adapters.
- `shell.html`: responsive interface and styles.
- `scriptable.js`: local journal, Home Screen widget, and WebView host.

Run `npm run build` from the repository root after editing these files. The generated `Pause.js` is the single file to install on iPhone.
