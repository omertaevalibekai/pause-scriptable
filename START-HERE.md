# Pause — установка на iPhone бесплатно

**Версия 0.1.0-alpha.1: экспериментальная. Проверка на реальном iPhone ещё не выполнена.**

Это первая версия личного трекера для **сигарет и IQOS / стиков**. Интерфейс целиком на английском. Она работает внутри бесплатного приложения Scriptable и показывает настоящий виджет на домашнем экране iPhone. Mac, Xcode, подписка и аккаунт Apple Developer не требуются.

## Что взять

- **Pause.js** — единственный файл, который нужен на iPhone. В нём уже есть интерфейс и логика. Файлы из `src` отдельно переносить не нужно.
- **Preview.html** — автономный интерактивный предпросмотр для Windows. Открой двойным щелчком в браузере.
- **Install.html** — английская инструкция с кнопкой копирования полного скрипта.

Данные предпросмотра хранятся в браузере, отдельно от iPhone. На телефоне приложение и виджет используют одно локальное хранилище. Стартовая история пустая — никаких выдуманных записей.

## Установка

1. На iPhone установи **Scriptable**, разработчик Simon B. Støvring: https://apps.apple.com/app/id1405459188. В магазине есть необязательные встроенные покупки; код Pause их не использует.
2. Перенеси **Pause.js** с Windows на iPhone любым удобным способом и сохрани в «Файлы».
3. Открой меню «Поделиться» у файла и выбери Scriptable, если этот вариант доступен. Если импорт не предлагается: открой файл как текст, скопируй **всё** содержимое, в Scriptable нажми **+** и вставь код. Можно также скопировать код со страницы **Install.html**.
4. Назови скрипт **Pause**. Запусти его кнопкой **▶**.
5. В первом окне оставь **IQOS sticks** и **Cigarettes**, затем нажми **Start my day**.
6. На домашнем экране iPhone удерживай пустую область → **Изменить → Добавить виджет** или **+** → **Scriptable** → **средний размер**.
7. Удерживай добавленный виджет → **Изменить виджет** → **Script: Pause**. Поле **Parameter** оставь пустым. Если видно **When Interacting**, выбери **Run Script**.

Средний и большой виджеты поддерживают отдельные зоны `+ Stick` и `+ Cigarette`. Маленький виджет открывает весь экран учёта: у него одна зона нажатия.

Опционально: добавь ещё один маленький виджет Scriptable, выбери тот же скрипт Pause и введи в поле **Parameter** слово **pause**. Это быстрый вход в экран помощи при тяге.

## Как пользоваться

- **+ Stick / + Cigarette** — записать употребление сейчас.
- **Undo last entry** — убрать последнюю добавленную запись, даже если её добавили задним числом. Это не удаляет всю историю.
- **Add a missed entry** — выбрать тип, прошлую дату и время; при желании указать триггер.
- **I feel like smoking** — выбрать Coffee, Stress, Work или Other и запустить паузу на три минуты. Таймер сохранится при закрытии интерфейса. Фонового звукового сигнала в этой версии нет.
- **The urge passed** — записать, что удалось переждать. **I smoked** — выбрать продукт; результат паузы и перекур сохранятся одним действием.
- **History** — открыть нужный день, удалить ошибочную запись, подтвердить полноту учёта. День без записей остаётся неизвестным, пока ты его не подтвердил. Новая или удалённая запись снимает подтверждение.
- **Plan** — выбрать продукты, при желании задать отдельные дневные цели и выбрать маленький шаг. Цель 0 означает намерение не употреблять; пустое поле означает отсутствие числовой цели. Программа не назначает темп снижения автоматически.
- **Plan → Export backup** — сохранить резервную копию в «Файлы». Для восстановления открой её как текст, скопируй содержимое и вставь в **Restore backup**. Импорт объединяет записи с имеющимися, без сброса истории.

## Ограничения бесплатного варианта

- Нажатие на `+` **открывает Scriptable**, сохраняет запись и показывает обновлённый экран. Это не полностью встроенная интерактивная кнопка нативного приложения.
- Частоту обновления домашнего виджета выбирает iOS. Дата и строка **Updated** помогают понять, когда он обновлялся. В самом интерфейсе сохранённая запись видна сразу.
- Скрипт работает офлайн, не запрашивает контакты, местоположение или доступ к здоровью, не отправляет аналитику. Внешняя ссылка на Smokefree открывается только по твоему нажатию.
- Данные находятся локально в контейнере Scriptable, папка `PauseData-v1/journal`. Удаление Scriptable может удалить данные: сначала экспортируй резервную копию. Другие скрипты внутри Scriptable технически могут иметь доступ к его локальным файлам; используй доверенные скрипты.
- Счётчики показывают количество эпизодов, а не дозу никотина. Переход между продуктами не считается отказом от табака.
- Первую установку на настоящем iPhone ещё нужно проверить: в среде разработки есть только Windows. Автоматические проверки не заменяют испытание Scriptable и виджета на телефоне.

## Быстрая проверка после установки

1. Запиши один стик через виджет. Убедись, что внутри Pause число увеличилось на 1.
2. Нажми Undo last entry, чтобы убрать пробную запись.
3. Повтори для сигареты.
4. Закрой и снова открой Pause — сохранённые данные должны остаться.
5. Запусти паузу, закрой экран, вернись: отсчёт должен продолжаться по времени окончания. Затем выбери End pause without a result.
6. Экспортируй резервную копию и сохрани её.

## Для продолжения разработки

Node.js 22+; сторонние пакеты и `npm install` не нужны.

```sh
node scripts/build.mjs
node --test tests/*.test.cjs
node scripts/serve.mjs
```

Локальный сервер открывает http://127.0.0.1:4173 только на этом компьютере. Для установки на телефон сервер не нужен. После правок `src` пересобери `Pause.js`, замени код скрипта на iPhone и сохрани прежнее имя. История хранится отдельно от кода.
