# Pause — implementation direction

Follow the approved iPhone concept, translated entirely into English. Personal use first: record, notice patterns, choose a small next step. No accounts, points, fabricated health metrics, or automatic medical taper.

- Colors: paper #F8F7F5, surface #FFFFFF, ink #25252B, coral #C95D43 (accessible primary buttons), soft peach #FAE9DF, lavender #9C99B2 for cigarette chart segments.
- Type: native Apple system sans-serif on iPhone; system fallbacks on Windows. Headings 30–34px, body 16px, supporting text >=12px. Tabular numerals for counts and timer.
- Layout: left-aligned single-column phone layout; one large recording card, compact weekly chart, one personal step. Bottom tabs Today / History / Plan. Craving sheet uses a large pause circle from the approved concept.
- Actions: full-width or paired large targets; visible keyboard focus; screen-reader labels; reduced motion; errors remain visible. Native widget uses the same colors, with English counts and separate links on medium/large sizes.
- Empty states are real. Unconfirmed days are not labeled smoke-free. A confirmed day is reopened if a smoking record changes. Numbers count episodes, not nicotine dose.

Review: the soft cards and coral are intentional because the user approved that design. Do not introduce a new visual direction. The browser preview has separate storage and clearly says so; the installed Scriptable dashboard and widget share a single local event journal.
